# MIST 脑环、指夹与温度联合采集使用说明

本程序在 Windows 本机完成设备连接、MIST 实验、阶段记录和文件保存。无需同时运行原厂 QtBLE、独立 PPG 或温度采集窗口；其他程序占用脑环或串口时应先退出，以免连接冲突。温度功能使用 GT-M601 蓝牙套件及其配套 USB 接收器，记录接触部位表面温度，不代表核心体温。

## 开始前

1. 下载 [v0.2.3 Windows 运行包](https://github.com/yangr8640-eng/mist-eeg-ppg/releases/download/v0.2.3/MIST-EEG-PPG-Windows-x64.zip)，完整解压后双击 `MIST-EEG-PPG.exe`，保留同目录的 `_internal` 文件夹。开发电脑也可使用本项目 `dist/MIST-EEG-PPG/MIST-EEG-PPG.exe`、指向它的现有快捷方式，或按项目 README 从源码启动。v0.2.3 支持再次实验与新目录命名，已通过软件测试；此前 v0.2.0 的实机功能验收记录见文末。
2. 开启电脑蓝牙、打开 QX-EEG-4 脑环和温度模块，连接 Arduino 指夹的 USB 及温度配套 USB 蓝牙接收器。按研究规范佩戴电极、指夹及柔性温度传感器，保持测量部位、固定方式和接触状态一致，尽量保持静止。
3. 确认本机有足够可写空间，选择保存目录。正式实验资料只保存到本机；不要将含被试信息的采集目录提交到公开 GitHub 仓库。
4. 使用模拟模式可先熟悉流程。模拟数据必须保持其模拟标记，不能用于真实被试数据分析。

## 连接与填写信息

在设备连接页扫描脑环、选择目标蓝牙设备；刷新串口列表后分别选择指夹和温度接收器所在的 COM 端口，再连接设备。两个串口必须不同。指夹使用现有 Example-3 每行一个 RED 整数的文本流，串口固定为 57600 baud；温度串口为 115200 baud、8 数据位、无校验、1 停止位。

温度套件通过配套 USB 蓝牙接收器输出串口数据；在 Windows 设备管理器中查找带 CH340 字样的端口，通过插拔对应接收器确认端口，不能仅凭名称与指夹混选。厂家说明套件出厂已配对；若失去配对，先用厂家 Windows 工具执行清除绑定、扫描和绑定，再退出厂家工具释放串口。当前程序不提供温度 GATT 直连或重新配对功能。

温度默认启用。如本次只采脑环和指夹，可在创建会话前关闭温度；创建会话后启用设备和测量设置锁定。启用的每路设备都必须持续输出有效数据至少 3 秒后，才能进入被试信息页。温度的准备检查还要求相邻有效更新间隔小于 1.5 秒；这是软件策略，厂家手册仅说明定时主动上报，未承诺固定周期。电脑记住蓝牙设备、出现串口或显示“已连接”并不足以说明正在接收有效生理信号。

侧栏显示各设备的连接、采集及接收速率；脑环电量显示原始状态，不应解释为校准百分比。温度面板显示最新摄氏温度、绝对温度趋势、当前阶段已存样本数及距上次有效更新的时间。过期提示表示该读数未继续更新，不能当作当前温度；已存数量按当前阶段计算，说明或评分期间只预览。

填写被试编号、年龄（1–120）、性别和可选备注。程序根据被试编号、性别和创建会话时的本地时间建立专属保存目录，并保存此次配置和实验信息。编号请遵循研究团队已有命名规则，避免重复混淆；需要保存操作员等其他信息时可填入备注。

启用温度时必须填写实际测量部位，例如左侧腕内侧或左手食指，并在备注补充固定方式、环境温度等研究需要的信息。柔性温度传感器测得的是接触部位表面温度；佩戴部位、接触状态和达到热平衡所需时间会影响读数，不能直接解释为核心体温。三秒准备检查只说明数据流稳定，不表示测温已达到热平衡。

## 六阶段实验

默认每阶段 180 秒，总正式阶段时间 18 分钟，不含说明和评分。阶段时间可在开始前调整，保存的配置会记录实际选择。

| 顺序 | 阶段 | 操作 |
| --- | --- | --- |
| 1 | 睁眼静息 | 按屏幕说明注视、保持静止 |
| 2 | 闭眼静息 | 按说明闭眼，阶段结束时听提示 |
| 3 | 算术练习 | 输入答案并按界面提示提交 |
| 4 | 对照任务 | 完成算术题，程序记录正确率和反应时 |
| 5 | 压力任务 | 在动态时限内作答，显示成绩及比较信息 |
| 6 | 恢复阶段 | 按说明放松、保持静止 |

每个阶段先显示说明，被试点击开始后开始该阶段记录；结束时自动停止该阶段写盘并保存。设备连接可能继续保持，方便预览和开始下一阶段；侧栏的“已连接”和“正在记录”是不同状态。

每阶段后的 VAS 评分为 0–100 的主观压力/焦虑程度。操作评分滑块后才能确认并进入下一阶段。阶段内若最后一题尚未完成就到达截止时间，记录为阶段截断，不按普通答错处理。

压力阶段的同伴平均和目标成绩是构造压力情境的预设比较值，并不代表真实其他被试成绩。实验结束时向被试说明这一设置；研究团队应按既定实验审批及告知流程组织实验。

## 中断、重做与结束

任一启用设备断开、发生采集错误，或连续 3 秒没有有效数据，程序停止当前阶段并保存为不完整。温度模块关闭、蓝牙链路中断时，USB 接收器的 COM 端口可能仍然存在；只要没有新的有效温度，仍会触发保护。检查佩戴、设备电量、蓝牙与 USB，重新连接并等到有效数据稳定后，重新执行当前阶段。

失败尝试不会覆盖，重做会形成新记录。不要把失败对照阶段的数据用于压力阶段校准。按 Esc 可请求结束实验，确认后保留已有数据和结束原因；不要通过直接关闭电源中止写盘。

完成六阶段及评分后，程序结束实验并保存结果。确认界面提示已保存，可以打开数据文件夹查看、点击“再次实验”或关闭程序。若出现磁盘写入错误，先保留已有文件及错误信息，处理空间或权限问题；存在写盘错误的阶段不能视为完整。

## 连续采集与再次实验

完成页和主动结束后的页面提供“再次实验”按钮；等待保存结束后即可点击，无需退出程序。程序释放上一轮设备和文件资源，返回最开始的设备连接页。

1. 为下一位被试重新佩戴设备，扫描并连接脑环，刷新并选择指夹及已启用温度的串口后连接。
2. 所有启用设备重新通过连续 3 秒有效数据检查后，填写被试信息。上次的编号、性别、备注和温度测量部位已清空，年龄恢复初始值 25，请按本次实际信息填写。
3. 保存位置、六阶段时长、模拟模式和温度启用设置保留，可以在新会话开始前调整。点击“保存信息，进入实验”，从第一个阶段重新开始。

每次新建独立数据目录，即使同一被试再次实验也不会覆盖先前记录；之前的答题、评分和压力任务校准数据不会带入下一次。重新准备期间，“再次实验”按钮显示“正在准备新实验…”，稍候即可。旧 v0.2.0 下载包不含此功能，请使用 v0.2.3 运行包。

## 保存内容与时间解释

v0.2.3 的保存目录格式为 `被试编号_性别_年月日_时分秒_微秒`，例如 `P001_女_20260921_093015_123456`。性别显示为“男”“女”；选择“其他 / 不愿透露”时使用“其他”。时间采用创建会话时的电脑本地时间，格式为 `YYYYMMDD_HHMMSS_ffffff`，24 小时制，微秒固定为六位。模拟记录额外放入 `SIMULATED` 子目录。

同一被试再次实验时使用新的时间生成目录。若完整名称仍与已有文件或目录相同，新目录自动追加 `_02`、`_03` 等序号，不复用或覆盖旧目录。已保存的旧格式目录保留原名；会话 ID 和完整时间记录仍保存在会话文件中。

| 文件或目录 | 内容 |
| --- | --- |
| `participant.json` | 被试信息 |
| `session.json` | 实验配置、启用设备、温度连接与测量部位、状态、时钟锚点及各阶段尝试 |
| `events.jsonl` | 阶段、刺激、连接等事件 |
| `trials.csv` | 题目、答案、正确性、反应时及截断等结果 |
| `ratings.csv` | 各阶段 VAS 评分 |
| `quality_report.json` | 结束时的接收速率、间隔及同步限制报告 |
| `eyes_open_睁眼静息_attempt_01/` | 睁眼阶段第一次尝试，其余阶段同理 |

每个阶段尝试目录包含 `stage.json`、`阶段key_eeg.csv`、`阶段key_ppg.csv`、`阶段key_eeg_raw.jsonl`、`阶段key_ppg_raw.jsonl`。例如睁眼阶段的 EEG 文件为 `eyes_open_eeg.csv`。重做使用 `attempt_02` 等新目录，保留失败尝试。分析前检查 `stage.json` 的状态和原因，不要把全部尝试简单合并为一次正常实验。

启用温度时同一目录增加 `阶段key_temperature.csv` 和 `阶段key_temperature_raw.jsonl`。例如 `eyes_open_temperature.csv` 中 `temperature_c` 为摄氏温度，`timing_basis` 固定为 `host_receive`；原始 JSONL 保留字节、解析异常与主机接收时刻。`session.json` 的 `enabled_devices` 标识此次实际启用的设备，`temperature.config` 保存连接设置和测量部位；禁用温度时不生成温度文件或温度配置项。

脑环标称每通道 500 Hz；PPG 按设备输出率保存，当前草图的 `delay(8)` 使输出约不超过 125 Hz，以界面及质量报告的实测速率为准。温度按实际有效报告保存，其低频更新不补点或伪造高频采样；质量报告用 3 秒作为温度长间隔阈值，约 1 秒的正常更新不会按 EEG/PPG 的 100 毫秒阈值计为异常。三个设备不必采用相同频率。接收速率只说明电脑实际收到多少有效数据。离线分析时使用时间字段对齐和重采样，保留原始数据。

程序使用共同的主机单调时间轴，同时保留 UTC 对应锚点。`received_ns` 是主机收到数据包的时间，脑环的 `estimated_sample_ns` 根据 500 Hz 和包内位置重建；PPG 和温度仅保留可观测的接收时刻。阶段文件按接收时刻划分，脑环估计时间靠近边界时可能跨出阶段，应在分析中明确裁剪规则。三种设备均没有可用的设备时间戳或序号，因此同步属于尽力的软件对齐，尚不能证明真实硬件采样达到毫秒级一致。详见 [协议与时间基准](PROTOCOL.md)。

## 实机验收与更换环境后的复验

2026-09-20，项目使用者确认脑环、指夹和 GT-M601 蓝牙温度套件三路实际联调及一次完整实验运行正常，v0.2.0 实机功能验收通过。记录依据为使用者的实测反馈，详见 [实机验收记录与复验指南](HARDWARE_ACCEPTANCE.md)。以后更换设备、电脑、固件或升级程序时，可按该指南复验并记录结果。

v0.2.0 EXE 保存的 `hardware_acceptance: not_verified` 为构建时默认字段，不会随本次人工验收更新；当前验收状态以验收记录为准。测量精度校准和硬件同步精度需另有专项证据。
