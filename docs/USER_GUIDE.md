# MIST 脑环与指夹联合采集使用说明

本程序在 Windows 本机完成设备连接、MIST 实验、阶段记录和文件保存。无需同时运行原厂 QtBLE 或独立 PPG 采集窗口；其他程序占用脑环或串口时应先退出，以免连接冲突。

## 开始前

1. 按项目 README 安装依赖并启动程序，或使用提供的 Windows 启动入口。
2. 开启电脑蓝牙、打开 QX-EEG-4 脑环，并连接 Arduino 指夹的 USB。按研究规范佩戴电极及指夹，尽量保持手部静止。
3. 确认本机有足够可写空间，选择保存目录。正式实验资料只保存到本机；不要将含被试信息的采集目录提交到公开 GitHub 仓库。
4. 使用模拟模式可先熟悉流程。模拟数据必须保持其模拟标记，不能用于真实被试数据分析。

## 连接与填写信息

在设备连接页扫描脑环、选择目标蓝牙设备；刷新串口列表后选择指夹所在 COM 端口，随后连接两种设备。指夹使用现有 Example-3 每行一个 RED 整数的文本流，串口固定为 57600 baud；其他固件格式需先适配。

两者都必须持续输出有效数据后，才能进入被试信息页。电脑记住蓝牙设备、出现串口或显示“已连接”并不足以说明正在接收有效生理信号。侧栏在整个过程中显示连接、采集及接收速率等信息；脑环电量显示原始状态，不应解释为校准百分比。

填写被试编号、年龄（1–120）、性别和可选备注。程序根据被试编号及实验开始日期时间建立专属保存目录，并保存此次配置和实验信息。编号请遵循研究团队已有命名规则，避免重复混淆；需要保存操作员等其他信息时可填入备注。

## 六阶段实验

默认每阶段 180 秒，总正式阶段时间 18 分钟，不含说明和评分。阶段时间可在开始前调整，保存的配置会记录实际选择。

| 顺序 | 阶段 | 操作 |
| --- | --- | --- |
| 1 | 睁眼静息 | 按屏幕说明注视、保持静止 |
| 2 | 闭眼静息 | 按说明闭眼，阶段结束时听提示 |
| 3 | 算术练习 | 输入答案并按界面提示提交 |
| 4 | 对照任务 | 完成算术题，程序记录正确率和反应时 |
| 5 | 压力任务 | 在动态时限内作答，显示成绩及比较信息 |
| 6 | 恢复阶段 | 按说明放松、保持静止 |

每个阶段先显示说明，被试点击开始后开始该阶段记录；结束时自动停止该阶段写盘并保存。设备连接可能继续保持，方便预览和开始下一阶段；侧栏的“已连接”和“正在记录”是不同状态。

每阶段后的 VAS 评分为 0–100 的主观压力/焦虑程度。操作评分滑块后才能确认并进入下一阶段。阶段内若最后一题尚未完成就到达截止时间，记录为阶段截断，不按普通答错处理。

压力阶段的同伴平均和目标成绩是构造压力情境的预设比较值，并不代表真实其他被试成绩。实验结束时向被试说明这一设置；研究团队应按既定实验审批及告知流程组织实验。

## 中断、重做与结束

任一设备断开、发生采集错误，或连续 3 秒没有有效数据，程序停止当前阶段并保存为不完整。检查佩戴、设备电量、蓝牙与 USB，重新连接并等到有效数据稳定后，重新执行当前阶段。

失败尝试不会覆盖，重做会形成新记录。不要把失败对照阶段的数据用于压力阶段校准。按 Esc 可请求结束实验，确认后保留已有数据和结束原因；不要通过直接关闭电源中止写盘。

完成六阶段及评分后，程序结束实验并保存结果。确认界面提示已保存，再断开设备或关闭程序。若出现磁盘写入错误，先保留已有文件及错误信息，处理空间或权限问题；存在写盘错误的阶段不能视为完整。

## 保存内容与时间解释

保存目录格式为 `被试编号_年月日_时分秒_微秒`，例如 `P001_20260920_101530_123456`。模拟记录额外放入 `SIMULATED` 子目录。

| 文件或目录 | 内容 |
| --- | --- |
| `participant.json` | 被试信息 |
| `session.json` | 实验配置、状态、时钟锚点及各阶段尝试 |
| `events.jsonl` | 阶段、刺激、连接等事件 |
| `trials.csv` | 题目、答案、正确性、反应时及截断等结果 |
| `ratings.csv` | 各阶段 VAS 评分 |
| `quality_report.json` | 结束时的接收速率、间隔及同步限制报告 |
| `eyes_open_睁眼静息_attempt_01/` | 睁眼阶段第一次尝试，其余阶段同理 |

每个阶段尝试目录包含 `stage.json`、`阶段key_eeg.csv`、`阶段key_ppg.csv`、`阶段key_eeg_raw.jsonl`、`阶段key_ppg_raw.jsonl`。例如睁眼阶段的 EEG 文件为 `eyes_open_eeg.csv`。重做使用 `attempt_02` 等新目录，保留失败尝试。分析前检查 `stage.json` 的状态和原因，不要把全部尝试简单合并为一次正常实验。

脑环标称每通道 500 Hz；PPG 按设备输出率保存，当前草图的 `delay(8)` 使输出约不超过 125 Hz，以界面及质量报告的实测速率为准。两个设备不必采用相同频率。接收速率只说明电脑实际收到多少有效数据。离线分析时使用时间字段对齐和重采样，保留原始数据。

程序使用共同的主机单调时间轴，同时保留 UTC 对应锚点。`received_ns` 是主机收到数据包的时间，脑环的 `estimated_sample_ns` 根据 500 Hz 和包内位置重建；PPG 仅保留可观测的接收时刻。阶段文件按接收时刻划分，脑环估计时间靠近边界时可能跨出阶段，应在分析中明确裁剪规则。两种设备均没有共同硬件时间戳或序号，因此同步属于尽力的软件对齐，尚不能证明真实硬件采样达到毫秒级一致。详见 [协议与时间基准](PROTOCOL.md)。

## 首次正式使用前

软件自动测试及模拟流程不代表硬件已验证。用真实设备完成一次完整预演，检查波形、每阶段文件、接收速率、中断保护和重做，按 [实物验收清单](PROTOCOL.md#实物验收清单) 保存验收结果后再用于正式研究。
