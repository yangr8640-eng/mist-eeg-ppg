# 软件验证与已知限制

本版本在 Windows 11 x64、Python 3.13.3 上开发验证。真实脑环和指夹暂在实验室，本版本的实物采集状态明确为 **待验收**。

自动化测试覆盖脑电符号极值和通道顺序、PPG 分帧及损坏输入、BLE 命令和异常清理、串口拔出、3 秒门禁、六个缩短阶段、评分、掉线重做、失败对照排除、数据保存边界和去重、延迟回调、队列溢出、写盘失败和窗口操作。真实模拟数据通过设备协议解析、共同控制器、后台写入器进入 CSV；缩短阶段用于软件验证，不代表已完成真实的 18 分钟实验。

源码 GUI 和打包后 EXE 均需走完模拟自检，生成六阶段文件、评分、事件和完成汇总后才能发布。每次发布的最终测试数量和打包结果记录在 GitHub Release 说明中。

本机 Windows BLE 扫描和串口枚举可以运行；设备缺席时不将其标记为连接成功。模拟数据保存在 `SIMULATED` 子目录，不作为真实实验数据。

尚待实际设备验证：

- 脑环固件是否使用已静态核对的 FE40/FE41/FE42 服务、100 字节通知和 500 Hz 输出。
- µV 换算、通道顺序、电极脱落状态与原厂软件/实际佩戴的对应关系。
- 指夹板卡上的固件是否确为 RED 整数流、57600 波特率，以及其真实输出频率。
- 长时间实际采集中的蓝牙丢失、串口间断、休眠和电源管理影响。
- 设备采样到主机接收的延迟，以及实际屏幕/声音呈现延迟。需要专用测试方法时按 [验收步骤](HARDWARE_ACCEPTANCE.md) 处理，不能用接收抖动冒充同步误差。

断电或强制结束程序时可能留下 `in_progress`/`recording` 状态以及最后一次刷新后尚未写入的数据；这些文件不能当成完成的阶段。可读的原始文件保留，程序不会覆盖同一尝试。当前不支持跨进程自动续做中断会话，应新建会话。
