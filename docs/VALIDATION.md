# 实机验收、软件验证与已知限制

**v0.2.0 实机功能验收通过，作为稳定版本发布。** 2026-09-20，项目使用者确认 QX-EEG-4 脑环、PPG 指夹和 GT-M601 蓝牙温度套件已全部实际试用，三路联调及一次完整实验均正常。验收来源是使用者实测反馈，范围见 [实机验收记录](HARDWARE_ACCEPTANCE.md)。

本项目在 Windows 11 x64、Python 3.13.3 上开发验证。v0.2.0 增加 GT-M601 蓝牙套件的配套 USB 接收器/CH340 串口温度通道。

自动化测试覆盖脑电符号极值和通道顺序、PPG 分帧及损坏输入、BLE 命令和异常清理、串口拔出、3 秒门禁、六个缩短阶段、评分、掉线重做、失败对照排除、数据保存边界和去重、延迟回调、队列溢出、写盘失败和窗口操作。温度回归范围包括严格 ASCII 帧及分片/多帧、异常报文、串口参数、低频准备与过期状态、可选启用、测量配置、温度数据与原始记录、阶段边界、重做和质量阈值。模拟数据通过设备协议解析、共同控制器、后台写入器进入 CSV；缩短阶段属于软件验证，用户完成的实机实验另记于验收记录。

源码 GUI 和打包后 EXE 均需走完模拟自检，生成六阶段三路文件、评分、事件和完成汇总后才能发布。自检使用六个 2 秒阶段及 1 Hz 模拟温度；真实温度设备的固定上报周期未由手册承诺。最终测试数量和打包结果以本次实际测试报告为准，本文件不把待执行的检查记作通过。

含温度功能的 v0.2.0 通过 [GitHub Release](https://github.com/yangr8640-eng/mist-eeg-ppg/releases/tag/v0.2.0) 作为稳定版本提供；[Windows 运行包下载](https://github.com/yangr8640-eng/mist-eeg-ppg/releases/download/v0.2.0/MIST-EEG-PPG-Windows-x64.zip)。开发电脑仍可使用 `dist/MIST-EEG-PPG/MIST-EEG-PPG.exe` 或指向它的现有快捷方式。旧 v0.1.0 下载包不含温度功能。

2026-09-20 v0.2.0 软件验证结果：自动化测试 **99 项通过**；源码模拟自检约 21.9 秒，打包 EXE 模拟自检约 21.8 秒并报告 `passed`。EXE 自检生成六阶段 × 三路共 18 个非空 CSV，每阶段含 2 个模拟温度点，记录 3 次答题和 6 次评分。这些软件结果与使用者的实机功能验收分别记录。

本次保持使用者已跑通的 EXE 不变，仅更新文档、Release 状态和包内文档。v0.2.0 EXE 生成的 `hardware_acceptance: not_verified` 是构建时默认字段，不会动态反映人工验收，当前状态应引用 [验收记录](HARDWARE_ACCEPTANCE.md)。`build-validation.json` 的 `hardware_tested: false` 如实描述模拟自检未操作真实硬件，保留该字段，不将模拟报告改写为实机测试报告。

本机 Windows BLE 扫描和串口枚举可以运行；设备缺席时不将其标记为连接成功。模拟数据保存在 `SIMULATED` 子目录，不作为真实实验数据。

本次实机功能验收之外仍需专项证据的范围：

- EEG 微伏量程校准、温度绝对精度及接触热平衡影响；温度记录仍为接触部位表面温度。
- 精确跨设备采样延迟与漂移、实际屏幕和声音呈现延迟；接收抖动不能代替毫秒级硬件同步测量。
- 全部断线、串口拔出、恢复配对、休眠和电源管理等故障注入情况；用户本次反馈未提供逐项测试明细。以后更换设备或环境时按 [复验指南](HARDWARE_ACCEPTANCE.md) 留存结果。

温度质量报告采用 3 秒接收间隔阈值，EEG/PPG 保留 100 毫秒指标；约 1 秒更新不会被误计为温度长间隔，间隔统计也不表示精确丢包数。所有启用通道都按同一主机接收时间切段，尚无设备时间戳、设备计数或共同硬件触发。

断电或强制结束程序时可能留下 `in_progress`/`recording` 状态以及最后一次刷新后尚未写入的数据；这些文件不能当成完成的阶段。可读的原始文件保留，程序不会覆盖同一尝试。当前不支持跨进程自动续做中断会话，应新建会话。
